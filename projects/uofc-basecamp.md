# I-001 — UofC Basecamp

## Purpose

UofC Basecamp is the proposed internal operating layer for curriculum, client context, project records, supervised communication, technical documentation, production reviews, deployment visibility, and reusable modules.

## Envisioned workflow

**Approved client communication → transcript → proposed scope/change → human approval → project/repository work → test → production review → deployment → client-visible status**

## Required modules

- client and relationship CRM;
- student portfolios, supervision, and the [12-week core curriculum](../docs/curriculum/README.md);
- project and artifact register;
- approved communication and transcription record;
- scope/change approval;
- repository and deployment references;
- production-review gates;
- incident, support, and offboarding records;
- curriculum and student reflection;
- reusable vertical-module catalog.

## Non-negotiable controls

- client and guardian consent where applicable;
- adult visibility for client/student communication;
- no automatic transcript-to-production action;
- organization-level data isolation;
- least-privilege roles;
- adult ownership of credentials and production approval;
- immutable approval and deployment history;
- rapid revocation when a student, client, or project leaves.

## Current implementation state

Concept only. No code repository, architecture, data model, hosting environment, or approved production system has been supplied.
