# UofC curriculum

This directory contains the durable teaching program for UofC learners. The curriculum is practical, project-based, and organized around one delivery loop:

**Problem → Scope → Architecture → Development Harness → Implement → Test → Secure → Deploy → Operate → Improve**

## How to use this material

- Instructors use the weekly outcomes and evidence requirements to plan sessions and reviews.
- Learners use the labs as a sequence, retaining their work in a version-controlled project repository.
- Project mentors use the rubric and production gates to assess work consistently.
- Future modules may extend the core by domain or technology, but should not weaken its security, verification, documentation, or operational requirements.

The core curriculum is framework-neutral. Teams may choose tools appropriate to a project, but every learner must be able to explain, inspect, test, repair, deploy, and operate the resulting system.
